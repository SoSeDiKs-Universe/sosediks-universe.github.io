## {% href_link 🌾 | Мʼякі блоки %}

{% symlink soft_blocks, Мʼякі блоки %} — це блоки, що помʼякшують падіння: усе, що на них приземляється, отримує менше шкоди від падіння. Це додається до помʼякшення, яке {% symlink hay_block, копиці соломи %} та {% symlink beds, ліжка %} мають і у ванілі.

Приземлення на `мʼякий блок`{: .mc-gold} після [стрибка віри](/wiki/misc/player_changes#стрибок-віри){: .mc-gold} повністю скасовує шкоду від падіння. На {% symlink leaves, листі %} гравець до того ж провалюється крізь шари під ним (по одному на кожні 5 блоків падіння, але не більше 7).

## {% href_link 📋 | Список мʼяких блоків %}

- {% symlink hay_block, Копиця соломи %}: без шкоди від падіння з висоти до 8 блоків, на 60% менше шкоди з більшої висоти.
- {% symlink wool, Вовна %}: на 50% менше шкоди від падіння.
- {% symlink beds, Ліжка %}: на 50% менше шкоди від падіння.
- {% symlink leaves, Листя %}: на 50% менше шкоди від падіння.
- {% symlink snow_layer_1, Сніг %}: на 50% менше шкоди від падіння.
- {% symlink snow_block, Сніговий блок %}: на 50% менше шкоди від падіння.
- {% symlink powder_snow, Сипкий сніг %}: на 50% менше шкоди від падіння.

{% symlink fragile_blocks, Крихкі блоки %} теж помʼякшують падіння (на 20% менше шкоди від падіння), але можуть від нього зламатися.
