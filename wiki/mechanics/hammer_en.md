## {% href_link 🔨 | Hammer %}

{% symlink hammer, Hammers %} are building tools.

`Hammers`{: .mc-gold} are used to:
- Place many building blocks: the `Hammer`{: .mc-gold} has to be in the other hand, and loses 1 durability per placed block (see the list below).
- Repair cracked blocks: hitting ({% game_action attack %}) a cracked block with a `Hammer`{: .mc-gold} (without sneaking) mends it. Each repair has a 10% chance to use up durability.
- Replace blocks in one go (see below).

### {% href_link ♻️ | Replacing blocks %}
With a `Hammer`{: .mc-gold} in the main hand and a block in the other one, breaking a different block replaces it with the held one. The new block keeps the old one's orientation and shape, like the direction of {% symlink stairs, Stairs %}.

Breaking still needs a proper tool, though it doesn't have to be in hand: the fastest fitting one from the inventory is used. Both tools lose 1 durability. For example, with a `Hammer`{: .mc-gold} and {% symlink oak_stairs, Oak Stairs %} in hands and an {% symlink axes, Axe %} in the inventory, breaking {% symlink acacia_stairs, Acacia Stairs %} replaces them with {% symlink oak_stairs, Oak Stairs %} facing the same way.
