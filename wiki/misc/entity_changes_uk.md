## {% href_link 💥 | Кріпери %}

### {% href_link 💣️ | Посилені ослаблені кріпери %}
Сила/радіус вибуху {% symlink creeper, кріпера %} залежить від його здоровʼя, що залишилося.

### {% href_link 🕶️ | Кріпери сталкерять гравців %}
{% symlink creeper, Крипери %} не почнуть запал, якщо їхня ціль їх не бачить. Якщо {% symlink creeper, кріпер %} опиниться позаду Вас, він буде чекати, поки Ви не повернетеся.

### {% href_link 😻 | Чарівні людські істоти %}
Незаряджені {% symlink creeper, кріпери %} не стануть вибухати, якщо немає небезпеки, а їхня ціль повзає.


## {% href_link 💤 | Ендермени %}

### {% href_link 🔄 | Телепортація жертв %}
{% symlink enderman, Ендермени %} можуть вирішити телепортувати своїх жертв, особливо якщо їх ціль знаходиться поза досяжністю.


## {% href_link 🐔 | Кури %}

### {% href_link 🪶 | Втрачені пірʼя %}
{% symlink chicken, Курка %} в 85% випадків буде самостійно виробляти {% symlink feather, пірʼя %} замість {% symlink egg, яєць %}.

### {% href_link 🥚 | Інкубаційні яйця %}
Розведення {% symlink chicken, курей %} виробляє 1-3 {% symlink egg, яєць %} замість {% symlink baby_chicken, курчат %}. {% symlink egg, Яйця %} вилуплюються при зникненні, якщо присутні умови для життя (якщо немає перенаселення).

## {% href_link 🐑 | Вівці %}

### {% href_link 👕 | Натуральна вовна %}

{% symlink evoker, Заклинач %} назавжди змінює натуральний колір {% symlink sheep, вівці %} після виконання заклинання "вололо".

### {% href_link 🌈 | Випадкова вовна %}
Веселкові {% symlink rainbow_sheep, вівці %} (з імʼям _jeb\__) скидають вовну випадкового кольору.

### {% href_link 🔥 | Палаюча вовна %}
{% symlink sheep, Вівці %}, будучи в вогні, втрачають вовну.

### {% href_link 🐺 | Страшні вовки %}
{% symlink sheep, Вівці %} намагаються втекти від {% symlink wolf, вовків %}.

{% symlink pillager, Поборники %} будуть намагатися рухатися, перезаряджаючи зброю.

{% symlink pillager, Поборники %} з чарами `«Мультипостріл»`{: .mc-aqua} на своїх {% symlink crossbow, арбалетах %} будуть намагатися залишатися ближче до цілі.

## {% href_link 🖼️ | Картини %}

### {% href_link 🪧 | Покращена стійкість %}
{% symlink painting, Картини %} більше не вимагають опори у вигляді стіни і можуть знаходитись в повітрі після встановлення (це заодно дозволяє встановлення на поверхні, що не є стінами). Вони також не випадають при наявності перешкод, дозволяючи ставити блоки чи інші сутності на те ж місце.

### {% href_link 🖌️ | Полегшений вибір картин %}
Використання ({% game_action use %}) {% symlink painting, картини %} на повітря в присіді дозволяє вибрати будь-який варіант картини.

### {% href_link ✂️ | Збереження варіації %}
Ламання {% symlink painting, картини %} призводить до випадання того ж варіанту, з яким вона була розміщена (включно з випадковим варіантом як окремим). При ламанні {% symlink painting, картини %} {% symlink shears, ножицями %} або `«Шовковим дотиком»`{: .mc-aqua} випадає картина зі збереженим варіантом, ігноруючи випадковий. Також можна натиснути ({% game_action use %}) на {% symlink painting, картину %} пустою рукою в присіді, щоб підібрати її (зберігаючи випадковий варіант).


## {% href_link 🏹 | Снаряди %}

### {% href_link 🔥 | Запалені снаряди поширюють вогонь %}
Палаючі снаряди поширять вогонь при приземленні.

Це включає:
- Запалювання блоків, таких як {% symlink campfire_block_unlit, багаття %}, {% symlink candle, свічки %} і {% symlink candle_cake, торт зі свічкою %}.
- Активація {% symlink tnt, динаміту %}, {% symlink tnt_minecart_entity, вагонетки з динамітом %} і {% symlink creeper, кріперів %}.
- Створення блоку {% symlink fire, вогню %} в місці приземлення.

### {% href_link 🎯 | Влучання снаряда (стріли/тризубця) %}
Влучання в {% symlink bee_nest, бджолине гніздо %} призведе до його падіння, випускаючи на волю розлючених бджіл.

Влучання в крихкий блок зламає його.

### {% href_link 🧯 | Гасіння водяним зіллям %}
Кидання {% symlink splash_water_potion, вибухової пляшки води %}/{% symlink lingering_water_potion, осідальної пляшки води %} тушить {% symlink torch, смолоскипи %}/{% symlink soul_torch, смолоскипи душ %}/{% symlink copper_torch, мідні смолоскипи %}.

### {% href_link ☃️ | Снігова битва! %}
{% symlink snowball, Сніжки %} створюють шар {% symlink snow_layer_1, снігу %} після приземлення (або випадають, якщо немає місця; потрапляння у відкрите {% symlink water, водне джерело %} перетворює його на {% symlink ice, лід %}). Крім того, взаємодія ({% game_action use %}) зі {% symlink snow_block, снігом %} порожньою рукою зменшить його шар, піднявши в руку {% symlink snowball, сніжок %}.

{% symlink snowball, Сніжки %} додають 5 секунд заморожування при влучанні в істоту. {% symlink snowball, Сніжки %} мають 4 такта часу перезарядки між кидками.

### {% href_link 🏹 | Стріли працюють у воді %}
Опір {% symlink arrow, стріл %} воді знижений, що дозволяє їм бути корисними під водою.


## {% href_link 🧩 | Різне %}

### {% href_link 🧟 | Освячення мерців %}
Вся мерці тепер мають пасивну регенерацію і блокують 80% вхідної шкоди, окрім вибухів. Це можна обійти, використовуючи зачарування `«Небесна кара»`{: .mc-aqua} (2 секунди вразливості, повна вхідна шкода), `«Полумʼя»`{: .mc-aqua} (20 секунд вразливості, якщо немає імунітету до вогню, інакше 7 секунд вимкнення регенерації; повна вхідна шкода) або запалюючи їх (20 секунд вразливості). Запалювання, звісно, ​​не працюватиме на істот, невразливих до вогню, наприклад, з Незера. Атаки від големів, інших неживих істот і вовків, спрямованих на скелетів, можуть тимчасово вимкнути регенерацію.

### {% href_link 🪣 | Більше істот, яких можна зачерпнути %}
Більше істот можна підібрати в {% symlink water_bucket, відро води %}:
- {% symlink frog, жаби %};
- {% symlink squid, спрути %} і {% symlink glow_squid, сяйні спрути %};
- {% symlink nautilus, навтилуси %} і {% symlink zombie_nautilus, зомбонавтилуси %} (якщо не агресивні).

Деяких істот можна підібрати в {% symlink lava_bucket, відро лави %}:
- {% symlink strider, блукачі %}.

Деяких істот можна підібрати в пусте {% symlink bucket, відро %}:
- {% symlink slime, слимаки %};
- {% symlink magma_cube, магмокуби %};
- {% symlink frog, жаби %}.

Деяких істот можна підібрати в {% symlink glass_bottle, пляшечку %}:
- {% symlink slime, слимаки %};
- {% symlink magma_cube, магмокуби %};
- {% symlink bee, бджілки %};
- {% symlink endermite, ендермайти %};
- {% symlink silverfish, лусківниці %}.

Деяких істот можна підібрати в {% symlink book, книгу %}:
- {% symlink allay, збирики %};
- {% symlink vex, бісики %}.

### {% href_link 🧟 | Нежить ігнорує шкоду оточення %}
Нежить не отримує шкоди від {% symlink cactus, кактусів %} та {% symlink sweet_berries, кущів %}.

### {% href_link 👁️ | Динамічний діапазон видимості %}
{% symlink blindness, Сліпота %} зменшує діапазон видимості на 90%.

Використання {% symlink spyglass, підзорної труби %} збільшує діапазон видимості удвічі.

### {% href_link 💢 | Злі тварини %}
Усі дружні істоти тепер можуть атакувати у відповідь замість паніки, і їхні друзі з радістю допоможуть їм у цьому. При пошкодженні істоти, створіння того ж типу стають злими, а тварини інших типів впадають у паніку.

### {% href_link 🆙 | Істоти намагаються займатися паркуром %}
Деякі істоти можуть перестрибувати прірви.

### {% href_link 🚪 | Відчинні хвіртки %}
Істоти, які можуть відчиняти {% symlink oak_door, двері %}, тепер також можуть відчиняти поодинокі {% symlink oak_fence_gate, хвіртки %}.

### {% href_link 🧨 | Вибухонебезпечні вагонетки можна підпалити вручну %}
{% symlink tnt_minecart_entity, Вагонетки з динамітом %} можуть бути активовані за допомогою {% symlink flint_and_steel, кресала %} або {% symlink fire_charge, вогняного заряду %}.

### {% href_link 🎇 | Знешкодження динаміту %}
{% symlink tnt, Динаміт %} та {% symlink tnt_minecart_entity, вагонетку з динамітом %} можна знешкодити при застосуванні {% symlink shears, ножиць %}.

### {% href_link 🔥 | Палаючі істоти поширюють вогонь %}
Палаючі істоти можуть розповсюджувати вогонь, якщо атакують голими руками.

Кинуті снаряди будуть підпалені, якщо їх стрілець горить.

### {% href_link 🚼️ | Більше діток %}
Усі (зменшувані) істоти, які не підлягають старінню, мають 5% шанс зʼявитися як маленька істота, включно зі {% symlink slime, слимаками %} та {% symlink magma_cube, магмакубами %}.

Для балансування та веселощів деякі істоти мають унікальну поведінку:
- Маленький {% symlink skeleton, скелет %} озброєний {% symlink trumpet, трубою %}, щоб викликати кровотечу з вух у істот навколо.
- Маленький {% symlink stray, примара %} оснащений {% symlink snowball, сніжками %} з камінчиком всередині (15 секунд `«Повільності»`{: .mc-aqua} при попаданні).
- Маленький {% symlink bogged, болотяник %} горить бажанням поділитися {% symlink red_mushroom, червоними %} та {% symlink brown_mushroom, коричневими грибами %} (2 секунди `«Отруєння»`{: .mc-aqua} при попаданні).
- Маленький {% symlink parched, засушень %} любить гратися з {% symlink sandstone_rock, уламками пісковика %} (15 секунд `«Слабкості»`{: .mc-aqua} при попаданні).
- Маленький {% symlink wither_skeleton, візер-скелет %} боїться {% symlink player, гравців %}, думаючи, що вони вкрадуть його {% symlink wither_skeleton_skull, череп візер-скелета %}, який вони завжди носять із собою. Ви можете обміняти череп, давши ({% game_action use %}) їм {% symlink wither_rose, троянду візера %}.

Такі маленькі істоти не ростуть.

### {% href_link 🐣 | Бідні малюки %}
У всіх істот-малюків здоровʼя зменшено вдвічі.

### {% href_link 😸 | Милі істоти %}
Багатьох істот можна погладити через {% game_action use %} в присіді з порожньою рукою.

{% symlink fox, Лисиці %} дозволяють гладити себе тільки довіреним гравцям.

### {% href_link 🩸 | Відключення шкоди по вихованцях %}
Вихованці більше не отримують пряму шкоду від власника або випущених ним снарядів.

Якщо необхідно вдарити (😿) вихованця, можна затиснути {% game_action sneak %} (присісти).

### {% href_link ❤️ | Частинки кохання %}
Тварини у режимі кохання (готові до розмноження) показують частинки серця протягом усього режиму кохання ([MC-93826]https://bugs.mojang.com/browse/MC/issues/MC-93826){: .mc-gold}).

### {% href_link ✂️ | Стрижка істот %}
{% symlink chicken, Курок %} можна час від часу стригти, щоб отримати 1-2 {% symlink feather, пірʼїн %}.

{% symlink horse, Коні %} та {% symlink mule, мули %} виробляють 2-4 {% symlink horsehair, кінського волосся %}.

{% symlink zombie_horse, Зомбоконі %} виробляють 1-2 {% symlink rotten_flesh, гнилої плоті %}.

{% symlink skeleton_horse, Коні-скелети %} виробляють 1 {% symlink bone_meal, кісткового борошна %}.
