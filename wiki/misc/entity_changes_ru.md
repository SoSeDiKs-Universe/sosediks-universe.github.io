## {% href_link 💥 | Криперы %}

### {% href_link 💣️ | Усиленные ослабевающие криперы %}
Сила/радиус взрыва {% symlink creeper, крипера %} зависит от его оставшегося здоровья.

### {% href_link 🕶️ | Криперы сталкерят игроков %}
{% symlink creeper, Криперы %} не начнут запал, если их цель их не видит. Если {% symlink creeper, крипер %} окажется позади Вас, он будет ждать, пока Вы не повернётесь.

### {% href_link 😻 | Очаровательные человеки %}
Незаряженные {% symlink creeper, криперы %} не станут взрываться, если нет опасности и их цель ползает.


## {% href_link 💤 | Эндермены %}

### {% href_link 🔄 | Телепортация жертв %}
{% symlink enderman, Эндермены %} могут решить телепортировать своих жертв, особенно если их цель находится вне досягаемости.


## {% href_link 🐔 | Курицы %}

### {% href_link 🪶 | Потерянные перья %}
{% symlink chicken, Курица %} в 85% случаев будет самостоятельно производить {% symlink feather, перья %} вместо {% symlink egg, яиц %}.

### {% href_link 🥚 | Инкубационные яйца %}
Разведение {% symlink chicken, куриц %} производит 1-3 {% symlink egg, яиц %} вместо {% symlink baby_chicken, цыплят %}. {% symlink egg, Яйца %} вылупляются при исчезновении, если присутствуют условия для жизни (если нет перенаселения).


## {% href_link 🐷 | Свиньи %}

### {% href_link 🐽 | Дополнительные детёныши %}
{% symlink pig, Свиньи %} производят от 2 до 6 детёнышей при размножении.


## {% href_link 🐑 | Овечки %}

### {% href_link 👕 | Натуральная шерсть %}
{% symlink sheep, Овечки %} всегда отращивают свою натуральную шерсть. Для получения других цветов каждый раз требуется краситель.

{% symlink evoker, Заклинатель %} навсегда изменяет натуральный цвет {% symlink sheep, овечки %} после выполнения заклинания "вололо".

### {% href_link 🌈 | Случайная шерсть %}
Радужные {% symlink rainbow_sheep, овцы %} (с названием _jeb\__) сбрасывает шерсть случайного цвета.

### {% href_link 🔥 | Сжигание шерсти %}
{% symlink sheep, Овечки %}, будучи в огне, теряют шерсть.

### {% href_link 🐺 | Страшные волки %}
{% symlink sheep, Овцы %} пытаются убежать от {% symlink wolf, волков %}.

{% symlink pillager, Разбойники %} будут пытаться двигаться во время перезарядки.

{% symlink pillager, Разбойники %} с зачарованием `«Тройной выстрел»`{: .mc-aqua} на своём {% symlink crossbow, арбалете %} будут пытаться держаться ближе к цели.

## {% href_link 🪵 | Стойки для брони %}

### {% href_link 🧰 | Стойки для брони имеют руки %}
{% symlink armor_stand_entity, Стойки для брони %} устанавливаются с руками и могут держать в них предметы.

### {% href_link 🤸 | Стойки для брони реагируют на редстоун %}
Подобно Bedrock версии, {% symlink armor_stand_entity, стойки для брони %} могут принимать различные позы в зависимости от сигнала редстоуна. При максимальном сигнале применяется случайная из поз.

## {% href_link 🖼️ | Картины %}

### {% href_link 🪧 | Улучшенная стойкость %}
{% symlink painting, Картины %} больше не требуют наличия стены и могут висеть в воздухе после установки (это заодно разрешает установку поверхности, которые не являются стенами). Они также не выпадают при наличии препятствий, позволяя ставить блоки или другие сущности на том же месте.

### {% href_link 🖌️ | Упрощённый выбор картин %}
Использование ({% game_action use %}) {% symlink painting, картины %} на воздух в приседе позволяет выбрать любой вариант картины.

### {% href_link ✂️ | Сохранение вариации %}
Разрушение {% symlink painting, картины %} приводит к выпадению того же варианта, с которым она была размещена (включая случайный вариант как отдельный). При ломании {% symlink painting, картины %} {% symlink shears, ножницами %} или `«Шёлковым касанием»`{: .mc-aqua} выпадает картина с сохранённым вариантом, исключая случайный. Также возможно нажать ({% game_action use %}) на {% symlink painting, картину %} пустой рукой в приседе, чтобы подобрать её (сохраняя случайный вариант).


## {% href_link 🏹 | Снаряды %}

### {% href_link 🔥 | Горящие снаряды распространяют огонь %}
Горящие снаряды распространят огонь при приземлении.

Сюда входит:
- Поджигание блоков, таких как {% symlink campfire_block_unlit, костры %}, {% symlink candle, свечи %} и {% symlink candle_cake, торт со свечкой %}.
- Активация {% symlink tnt, динамита %}, {% symlink tnt_minecart_entity, вагонетки с динамитом %} и {% symlink creeper, криперов %}.
- Создание блока {% symlink fire, огня %} в месте приземления.

### {% href_link 🎯 | Попадания снарядов (стрел/трезубцев) %}
Попадание в {% symlink bee_nest, пчелиное гнездо %} заставит его упасть, выпустив разъяренных пчёл.

Попадание в хрупкий блок сломает его.

### {% href_link 🧯 | Тушение водным зельем %}
Бросок {% symlink splash_water_potion, взрывной бутылочки воды %}/{% symlink lingering_water_potion, бутылочки с водяной взвесью %} тушит {% symlink torch, факелы %}/{% symlink soul_torch, факелы душ %}/{% symlink copper_torch, медные факелы %}.

### {% href_link ☃️ | Снежный бой! %}
{% symlink snowball, Снежки %} создают слой {% symlink snow_layer_1, снега %} при приземлении (или выпадают сами, если нет места; попадание в открытый {% symlink water, водный источник %} превращает его в {% symlink ice, лёд %}). Кроме того, взаимодействие ({% game_action use %}) со {% symlink snow_block, снегом %} пустой рукой уменьшит его слой, при этом подняв в руку {% symlink snowball, снежок %}.

{% symlink snowball, Снежок %} добавляет 5 секунд замораживания при попадании в сущность. {% symlink snowball, Снежки %} имеют 4 тика времени перезарядки между бросками.

### {% href_link 🏹 | Стрелы работают в воде %}
Сопротивление {% symlink arrow, стрел %} воде понижено, что позволяет им быть полезными под водой.


## {% href_link 🧩 | Разное %}

### {% href_link 🧟 | Посвящение нежити %}
Вся нежить теперь имеет пассивную регенерацию и блокируют 80% входящего урона, кроме взрывов. Это можно обойти, используя зачарование `«Небесная кара»`{: .mc-aqua} (2 секунды уязвимости, полный урон), `«Воспламенение»`{: .mc-aqua} (20 секунд уязвимости, если нет иммунитета к огню, иначе 7 секунд отключения регенерации; полный урон) или поджигая их (20 секунд уязвимости). Поджог, конечно, не будет работать на существ, неуязвимых к огню, например, из Незера. Атаки от големов, другой нежити и волков, нацеленных на скелетов, могут временно отключить регенерацию.

### {% href_link 🪣 | Больше существ, которых можно зачерпнуть %}
Больше существ можно подобрать в {% symlink water_bucket, ведро воды %}:
- {% symlink frog, лягушки %};
- {% symlink squid, спруты %} и {% symlink glow_squid, светящиеся спруты %};
- {% symlink nautilus, наутилусы %} и {% symlink zombie_nautilus, наутилусы-зомби %} (если не агрессивные).

Некоторых существ можно подобрать в {% symlink lava_bucket, ведро лавы %}:
- {% symlink strider, лавомерки %}.

Некоторых существ можно подобрать в пустое {% symlink bucket, ведро %}:
- {% symlink slime, слизни %};
- {% symlink magma_cube, магмовые кубы %};
- {% symlink frog, лягушки %}.

Некоторых существ можно подобрать в {% symlink glass_bottle, бутылочку %}:
- {% symlink slime, слизни %};
- {% symlink magma_cube, магмовые кубы %};
- {% symlink bee, пчёлы %};
- {% symlink endermite, эндермиты %};
- {% symlink silverfish, чешуйницы %}.

Некоторых существ можно подобрать в {% symlink book, книгу %}:
- {% symlink allay, тихони %};
- {% symlink vex, вредины %}.

### {% href_link 🧟 | Нежить игнорирует урон окружения %}
Нежить не получает урон от {% symlink cactus, кактусов %} и {% symlink sweet_berries, кустов %}.

### {% href_link 👁️ | Динамический диапазон видимости %}
{% symlink blindness, Слепота %} уменьшает диапазон видимости на 90%.

Использование {% symlink spyglass, подзорной трубы %} увеличивает диапазон видимости в два раза.

### {% href_link 💢 | Злые животные %}
Все дружественные существа теперь могут атаковать в ответ вместо паники, и их друзья с радостью помогут им в этом. При нанесении урона существу, существа того же вида впадают в ярость, а животные других видов впадают в панику.

### {% href_link 🆙 | Сущности пытаются заниматься паркуром %}
Некоторые сущности могут перепрыгивать через пропасти.

### {% href_link 🚪 | Открываемые калитки %}
Сущности, которые могут открывать {% symlink oak_door, двери %}, теперь также могут открывать одиночные {% symlink oak_fence_gate, калитки %}.

### {% href_link 🧨 | Взрывчатые вагонетки можно поджечь вручную %}
{% symlink tnt_minecart_entity, Вагонетки с динамитом %} могут быть активированы при помощи {% symlink flint_and_steel, огнива %} или {% symlink fire_charge, огненного заряда %}.

### {% href_link 🎇 | Обезвреживание динамита %}
{% symlink tnt, Динамит %} и {% symlink tnt_minecart_entity, вагонетку с динамитом %} можно обезвредить при применении {% symlink shears, ножниц %}.

### {% href_link 🔥 | Горящие сущности распространяют огонь %}
Горящие существа могут распространять огонь, если атакуют голыми руками.

Брошенные снаряды загорятся, если горит их стрелок.

### {% href_link 🚼️ | Больше детей %}
Все (уменьшаемые) нестареющие существа имеют 5% шанс появиться в виде маленького существа, включая {% symlink slime, слизней %} и {% symlink magma_cube, магмовых кубов %}.

Для балансировки и веселья некоторые сущности имеют уникальное поведение:
- Маленький {% symlink skeleton, скелет %} вооружён {% symlink trumpet, трубой %}, чтобы вызывать кровотечение из ушей у сущностей вокруг.
- Маленький {% symlink stray, зимогор %} оснащён {% symlink snowball, снежками %} с камешком в примеси (15 секунд `«Замедления»`{: .mc-aqua} при попадании).
- Маленький {% symlink bogged, болотник %} горит желанием поделиться {% symlink red_mushroom, красными %} и {% symlink brown_mushroom, коричневыми грибами %} (2 секунды `«Отравления»`{: .mc-aqua} при попадании).
- Маленький {% symlink parched, пустынник %} любит играться с {% symlink sandstone_rock, осколками песчаника %} (15 секунд `«Слабости»`{: .mc-aqua} при попадании).
- Маленький {% symlink wither_skeleton, визер-скелет %} боится {% symlink player, игроков %}, думая, что они украдут его {% symlink wither_skeleton_skull, череп визер-скелета %}, который они всегда носят с собой. Вы можете обменять череп, дав ({% game_action use %}) им {% symlink wither_rose, розу визера %}.

Такие маленькие существа не растут.

### {% href_link 🐣 | Бедные малыши %}
У всех существ-малышей здоровье уменьшено вдвое.

### {% href_link 😸 | Милые существа %}
Многих существ можно погладить через {% game_action use %} в приседе с пустой рукой.

{% symlink fox, Лисы %} позволяют гладить себя только доверенным игрокам.

### {% href_link 🩸 | Отключение урона по питомцам %}
Питомцы больше не получают прямой урон от владельца или выпущенных им снарядов.

Если необходимо ударить (😿) питомца, можно зажать {% game_action sneak %} (присесть).

### {% href_link ❤️ | Частицы любви %}
Животные в режиме любви (готовые к размножению) показывают частицы сердца на протяжении всего режима любви ([MC-93826](https://bugs.mojang.com/browse/MC/issues/MC-93826){: .mc-gold}).

### {% href_link ✂️ | Стрижка сущностей %}
{% symlink chicken, Куриц %} можно время от времени стричь, чтобы получить 1-2 {% symlink feather, пера %}.

{% symlink horse, Лошади %} и {% symlink mule, мулы %} производят 2-4 {% symlink horsehair, лошадиных волос %}.

{% symlink zombie_horse, Лошади-зомби %} производят 1-2 {% symlink rotten_flesh, гнилой плоти %}.

{% symlink skeleton_horse, Лошади-скелеты %} производят 1 {% symlink bone_meal, костную муку %}.
