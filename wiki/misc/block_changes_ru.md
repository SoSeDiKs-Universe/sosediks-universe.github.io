## {% href_link 🏞️ | Окружающая среда %}

### {% href_link 🔥 | Костёр может поджечь %}
Если сущность становится на зажжённый {% symlink campfires, костёр %}, то огонь распространится на неё. Зачарование {% symlink frost_walker, Ледоход %} на ботинках предотвращает это.

### {% href_link 🌧️ | Костры затухают от дождя %}
Если {% symlink campfires, костёр %} находится под прямым попаданием дождя, то он затухает.

### {% href_link 🧊 | Тающий лёд в Незере %}
Обычный {% symlink ice, лёд %} мгновенно тает в сверхтёплых измерениях, таких как Незер. {% symlink packed_ice, Плотный лёд %} тоже тает со временем (независимо от ограничений ванили по умолчанию, таких как уровень освещенности). {% symlink blue_ice, Синий лёд %}, с другой стороны, способен выдерживать столь высокие температуры.

### {% href_link 🐾 | Умные тропинки %}
Если ходить по одному и тому же пути в течение некоторого времени, блоки могут измениться. {% symlink grass_block, Дёрн %} / {% symlink podzol, подзол %} превратится в {% symlink dirt, землю %}, затем в {% symlink coarse_dirt, каменистую землю %}, затем в {% symlink gravel, гравий %} и наконец в {% symlink cracked_stone_bricks, потрескавшиеся каменные кирпичи %}. {% symlink sand, Песок %} / {% symlink red_sand, красный песок %} превратится в {% symlink sandstone, песчаник %} / {% symlink red_sandstone, красный песчаник %}.

### {% href_link 🌱 | Распространение травы %}
{% symlink grass_block, Дёрн %} (и другие травяные блоки) может распространиться на {% symlink coarse_dirt, каменистую землю %}, превращая её в {% symlink dirt, землю %}.

### {% href_link 🍃 | Нетвёрдая листва %}
Сущности могут проходить сквозь {% symlink leaves, листву %}.

### {% href_link 👟 | Окружение влияет на скорость передвижения %}
Скорость передвижения является динамичной и постоянно изменяется. Ходьба по {% symlink dirt_path, тропе %} будет быстрее ходьбы по {% symlink dirt, земле %}, а растительность на пути напротив замедляет.

### {% href_link 🧨 | Взрывы работают в жидкостях %}
Жидкости больше не предотвращают взрывы.



## {% href_link 🔧 | Механики %}

### {% href_link 🔄 | Совместное разрушение мира %}
Разрушение блоков происходит совместно между игроками, а трещины остаются на месте в течение некоторого времени. Потресканный блок можно починить, стукнув ({% game_action attack %}) нему {% symlink hammer, молотком %}.

### {% href_link 🌊 | Падение в лужи болезненно %}
Падение в лужу (один блок {% symlink water, воды %}) наносит урон, Вы больше не сможете спастись с помощью {% symlink water_bucket, ведра воды %}).

### {% href_link 🔔 | Стук-стук и динь-донь %}
По {% symlink doors, дверям %} и {% symlink trapdoors, люкам %} можно стучать при помощи {% game_action attack %}. Если рядом с ними есть {% symlink buttons, кнопка %}, то {% game_action attack %} по ней будет действовать как дверной звонок.

### {% href_link 🐈 | Котейка не даёт открыть сундук? %}
Открытие {% symlink chest, сундука %} отбрасывает сущности на нём в направлении крышки. Но будьте осторожны! Если позади крышки есть стена или во время закрытия крышки на {% symlink chest, сундуке %} находится моб, то сущность получит единицу урона.

### {% href_link ⚙️ | Умное открытие дверей %}
{% symlink doors, Двери %}, {% symlink trapdoors, люки %} и {% symlink fence_gates, калитки %} открываются вместе, если находятся рядом. Это можно предотвратить, будучи в приседе, или, в случае редстоуна, сигналом меньше 8.

### {% href_link 🚪 | Высокие двери %}
Установка открытого {% symlink trapdoors, люка %} (одного или двух) над {% symlink doors, дверью %} позволит открывать их вместе одновременно.

### {% href_link 💧 | Хранилища выбрасывают предметы в жидкостях %}
Если открыть хранилище в окружении жидкости, то все предметы внутри ринутся наружу. Будьте особенно осторожны с лавой.

### {% href_link 🍈 | Взрывные арбузы и тыквы %}
Если в {% symlink melon, арбуз %} или {% symlink pumpkin, тыкву %} попадёт {% symlink arrows, стрела %} или {% symlink trident, трезубец %}, то блок сломается на части.

### {% href_link 💥 | Взрывная угольная руда %}
{% symlink coal_ores, Угольные руды %} (любого вида) не любят {% symlink fire, огонь %} и взрываются при контакте с ним. Это включает зажжённые {% symlink torches, факелы %} (любого вида) и {% symlink campfires, костры %}, а также зачарование {% symlink fire_aspect, Заговор огня %}.

Более того, попытка добыть руду металлическим инструментом приведёт к тому же результату, создав огненный взрыв 5-го уровня в обоих случаях.

### {% href_link 🚧 | Перепрыгивание через заборы %}
{% symlink player, Игроки %} могут перепрыгивать через {% symlink fences, заборы %}, но они всё ещё являются препятствием для остальных сущностей.

### {% href_link 🔥 | Огонь распространяется при прикосновении %}
{% symlink fire, Огонь %} распространяется при попытке потушить его пустой рукой.

### {% href_link 🧯 | Незажжённый костёр %}
{% symlink campfires, Костры %} больше не горят по умолчанию. При разрушении {% symlink campfires, костёр %} выпадает как предмет, а {% symlink silk_touch, Шёлковое касание %} позволяет сохранить зажжённое состояние.

### {% href_link 💧 | Мокрые котлы %}
Сущности, находящиеся внутри {% symlink water_cauldron, котлов с водой %}, считаются мокрыми ([MC-145311](https://bugs.mojang.com/browse/MC/issues/MC-145311){: .mc-gold}).

### {% href_link ⬇️ | Костры подвержены гравитации %}
Если под {% symlink campfires, костром %} отсутствует точка опоры, то он упадёт вниз. По приземлению, горящий {% symlink campfires, костёр %} потухает и распространяет огонь на блок снизу и, с некоторой вероятностью, на блоки вокруг.

### {% href_link 👁️ | Наблюдатель реагирует на сущности %}
{% symlink observer, Наблюдатели %}, если не направлены на твёрдый блок, выдают сигнал, когда замечают движущуюся сущность перед собой.

### {% href_link 🎴 | Одинарное разрушение плит %}
При разрушении двойной плиты в приседе ({% game_action sneak %}) выпадет только та плита, на которую смотрит игрок.

### {% href_link 🪡 | Острый камнерез %}
{% symlink stonecutter, Камнерез %} наносит урон (2 единицы за такт урона) существам, стоящим на нём.

### {% href_link 🎶 | Менее ограниченные нотные блоки %}
{% symlink note_block, Нотный блок %} воспроизводит ноту, если любой соседний блок не является твёрдым, а не только если блок над ним является воздухом.

### {% href_link 🎼 | Обратная настройка нотного блока %}
Настройка {% symlink note_block, нотного блока %} в приседе ({% game_action sneak %}) понизит его тональность вместо повышения.



## {% href_link ⚙️ | Мелочи %}

### {% href_link 🪚 | Полезный каменорез %}
Многие рецепты были убраны из других блоков-станций и добавлены в {% symlink stonecutter, камнерез %}. Теперь такие вещи, как двери, плиты, таблички, кнопки и т.д., создаются через резку и могут быть взаимозаменяемы в соотношении 1 к 1 (да, деревянную кнопку можно превратить в деревянную дверь того же типа).

### {% href_link 🔲 | Плачущий обсидиан — это обсидиан %}
{% symlink crying_obsidian, Плачущий обсидиан %} может использоваться в качестве блока для рамки портала в Незер.

### {% href_link 🪧 | Улучшенное редактирование табличек %}
Окно редактирования {% symlink signs, табличек %} больше не открывается автоматически при установке.

{% symlink signs, Таблички %} сохраняют текст на них и отображают его в инвентаре. Нажатие {% game_action use %} {% symlink signs, табличкой %} в руке по {% symlink signs, табличке %} в мире применит на неё сохранённый текст. Текст можно стереть, разместив табличку в сетке крафта.

### {% href_link 📦 | Облегчённый доступ к хранилищам %}
При взаимодействии ({% game_action use %}, без приседа) с {% symlink item_frame, рамками %}, {% symlink painting, картинками %} и {% symlink signs, табличками %} открывается инвентарь блока, который находится за ними.

Некоторые ванильные блоки получили инвентарь. {% symlink flower_pot, Цветочные горшки %} имеют 5 слотов, в которые можно прятать предметы.

### {% href_link 🎶 | Улучшенный нотный блок %}
{% symlink note_block, Нотные блоки %} показывают ноту и инструмент, которые сейчас проигрываются.

### {% href_link 🕸️ | Легковоспламеняющаяся паутина %}
{% symlink cobweb, Паутина %} может гореть и перенимать {% symlink fire, огонь %}.

### {% href_link 🛤️ | Улучшенная установка рельс %}
{% symlink rails, Рельсы %} могут устанавливаться на большее количество поверхностей.

### {% href_link 🔁 | Улучшенные заменяемые блоки %}
Заменяемые блоки ломаются при размещении на них блоков, выбрасывая сгенерированный лут.

{% symlink pink_petals, Розовые лепестки %} и {% symlink wildflowers, полевые цветы %} добавлены в список заменяемых блоков.
